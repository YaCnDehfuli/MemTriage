# Report examples

These are the supplied, reviewed reports for the controlled `2580_5.vmem`
investigation, preserved byte-for-byte:

- [Executive PDF](MemTriage-executive-report.pdf) — one page.
- [Technical PDF](MemTriage-technical-report.pdf) — six pages.
- [Executive review notes](Executive-report-notes.txt).
- [Technical review notes](Technical-report-notes.txt).

The reviewed examples expand and qualify the saved application export. They
include five selected objects and five memory exhibits; the saved UI captured
for the project report had three selected objects and one memory exhibit.
They are not presented as untouched automatic exports or as evidence of a
production compromise. The notes document the revisions and interpretation.

See the [project report](../index.html), [recording guide](../demo/report-writing-demo.md),
and [saved evidence extract](../demo/report-writing-evidence.json).
